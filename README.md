## 🚀 Como Executar o Projeto

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/GustavoAlbuq/front_end_avancado_2025.git

2. Acesse o diretório do projeto:
cd front_end_avancado_2025

3.Instale as dependências:
npm install 

4.Execute o projeto:
npm run dev

5.Abra no navegador:
O terminal exibirá o endereço local, geralmente:
http://localhost:5173/
